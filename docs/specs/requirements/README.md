# Requirements & Discovery

> Thư mục lưu trữ các tài liệu đặc tả yêu cầu ở giai đoạn sơ khởi (Draft/Discovery Requirements), thảo luận tính năng trước khi được chốt thành Business Spec chính thức.

## Quy ước cấu trúc:
- Tạo thư mục con theo mã chức năng: `requirements/<MÃ_CHỨC_NĂNG>/`
- Ví dụ: `requirements/FEAT-01-AUTH/draft.md`
