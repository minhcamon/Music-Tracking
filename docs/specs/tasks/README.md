# Tasks & Implementation Plans

> Thư mục lưu trữ kế hoạch bóc tách công việc (Implementation Plan / Task Breakdown) cho các tính năng phức tạp hoặc thay đổi kiến trúc lớn.

## Cấu trúc khuyến nghị cho Kế hoạch Tính năng:
- Tạo theo mã chức năng: `tasks/<MÃ_CHỨC_NĂNG>/task-plan.md`
- Tuân thủ cấu trúc **Plan 9 mục** của dự án:
  1. Goal & Scope
  2. Data Flow
  3. Affected Modules
  4. API / Interface Changes
  5. UI / UX Impact
  6. Edge Cases
  7. Risks & Assumptions
  8. Testing Strategy
  9. Architecture Impact
